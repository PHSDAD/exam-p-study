# Exam P 學習站

靜態 Exam P 學習網站，包含知識點、210 道原創練習題、隨機練習、限時模考及可列印題本。

## 開啟網站

GitHub Pages 的入口為 `index.html`；`閱讀入口.html` 保留為相容入口。所有樣式、程式與數學字型均隨網站提供。

在 GitHub 儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**，再選擇放置本目錄檔案的分支及 **/(root)**。無須建置工具或額外工作流程。

## 內容來源

這是獨立學習整理，並非 SOA、ASM 或 Prometric 的官方網站，也未獲其認證。練習題均有原創來源標記；SOA 官方考綱與公開樣題透過原站連結取得。部署內容不包含 ASM 掃描書、付費教材原文、未公開考題或來源資料檔。

考試範圍與規則請以 [SOA Exam P 官方學習頁](https://www.soa.org/education/exam-req/edu-exam-p-detail/study/)及當期考綱為準。KaTeX 依 `assets/KATEX_LICENSE.txt` 所載授權提供。

## 作答資料

作答進度和模考狀態儲存在目前瀏覽器的本機儲存空間，不會提交至 GitHub 或其他伺服器。網站沒有帳號、後端、分析追蹤或雲端同步；提供的 CSV 均為空白練題模板。

`file://` 本機版與 `https://` 線上版屬於不同來源，作答進度分開保存；更換瀏覽器、裝置或網域也不會自動沿用。可使用網站的匯出功能下載作答記錄。網站更新不會主動清除同一網址下的既有進度。
